# 🌸 Kingdom Kids — Jesus Army Bible Adventure

24-chapter gamified Hindi Bible revision app for children. Vite + React + Tailwind.

## Run locally
```
npm install
npm run dev
```

## Build for production
```
npm run build
npm run preview
```

## Deploy to GitHub Pages
```
npm install --save-dev gh-pages
npm run build
npx gh-pages -d dist
```
